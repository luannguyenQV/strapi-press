# Getting Started with StrapiPress

A step-by-step guide to get started with the StrapiPress project.

---

## Prerequisites

Before starting, ensure you have:

| Requirement | Version | Check Command |
|-------------|---------|---------------|
| Node.js | 18.0.0 - 22.x.x | `node --version` |
| pnpm | 10.22.0+ | `pnpm --version` |
| Git | Any recent | `git --version` |

**Install pnpm** (if not installed):
```bash
npm install -g pnpm
```

---

## Step 1: Clone & Install Dependencies

```bash
# Clone the repository
git clone <your-repo-url> strapipress
cd strapipress

# Install all workspace dependencies
pnpm install
```

---

## Step 2: Environment Setup

### Strapi Backend (.env)
The project already has environment variables configured. For a fresh setup:

```bash
# Navigate to Strapi app
cd apps/strapi

# Check if .env exists, if not copy from example
cp .env.example .env  # Only if .env doesn't exist
```

**Required variables** (already set for development):
```env
HOST=0.0.0.0
PORT=1337
DATABASE_CLIENT=sqlite  # Use SQLite for development
APP_KEYS=<auto-generated>
JWT_SECRET=<auto-generated>
ADMIN_JWT_SECRET=<auto-generated>
```

### Next.js Frontend
```bash
cd apps/web
cp .env.example .env.local  # Only if needed
```

**Key variable**:
```env
NEXT_PUBLIC_STRAPI_URL=http://localhost:1337
```

---

## Step 3: Configure Permissions (CRITICAL - REQUIRED)

This step configures the role-based access control for your social blogging platform:

```bash
# From project root
cd apps/strapi
pnpm seed:permissions
```

**What this does**:
- Configures **Public role**: Read-only access to articles, categories, tags
- Configures **Authenticated role**: Full CRUD on own content
- Sets default role for new user registrations

**Expected output**:
```
============================================================
  Permission & Role Configuration
============================================================

Public permissions configured
Authenticated permissions configured
Default role set to Authenticated

Permissions and roles configured successfully!
```

---

## Step 4: Start Strapi Backend

```bash
# From project root
pnpm dev:strapi
```

**Wait for**:
```
[strapi] Starting Strapi...
[strapi] Strapi started successfully
```

**Access points**:
- Admin Panel: http://localhost:1337/admin
- API: http://localhost:1337/api

---

## Step 5: Create Admin User

On first access to http://localhost:1337/admin, you'll see a registration form:

1. Open http://localhost:1337/admin in your browser
2. Fill in the registration form:
   - First name
   - Last name
   - Email
   - Password (min 8 characters)
3. Click "Let's start"

**Alternative** (command line):
```bash
cd apps/strapi
pnpm strapi admin:create-user
```

---

## Step 6: Seed Sample Data (OPTIONAL - For Testing)

If you want realistic test data:

```bash
cd apps/strapi
pnpm seed:social
```

**What this creates**:
- 10 users (password: `password123`)
- 5 categories
- 20 tags
- 30 articles with comments, likes, bookmarks, follows

**Custom amounts**:
```bash
USERS=20 ARTICLES=50 pnpm seed:social
```

---

## Step 7: Start Next.js Frontend

Open a **new terminal**:

```bash
# From project root
pnpm dev:web
```

**Access**: http://localhost:3001

---

## Step 8: Verify Everything Works

### Test the API:
```bash
# Get all articles
curl http://localhost:1337/api/articles

# Get categories
curl http://localhost:1337/api/categories

# Get site settings
curl http://localhost:1337/api/global
```

### Test the Frontend:
1. Open http://localhost:3001
2. You should see the blog homepage
3. Navigate to articles, categories

| Task | Command |

## Troubleshooting

### "Permissions not configured" error
```bash
cd apps/strapi && pnpm seed:permissions
```

### Port already in use
```bash
# Kill process on port 1337
lsof -ti:1337 | xargs kill -9

# Kill process on port 3001
lsof -ti:3001 | xargs kill -9
```

### Database issues (reset everything)
```bash
cd apps/strapi
rm -rf .tmp/data.db  # Delete SQLite database
pnpm dev:strapi      # Restart (creates fresh DB)
pnpm seed:permissions # Re-run permissions
```

### Clear all caches
```bash
pnpm clean
pnpm install
```
