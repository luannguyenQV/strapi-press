# API Reference

Complete REST API documentation for the StrapiPress social blogging platform.

**Base URL**: `http://localhost:1337/api`

---

## Authentication

All authenticated endpoints require a JWT token in the Authorization header:

```bash
Authorization: Bearer <jwt_token>
```

### Login

```bash
POST /api/auth/local
```

**Request Body:**
```json
{
  "identifier": "user@example.com",
  "password": "password123"
}
```

**Response:**
```json
{
  "jwt": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "username": "johndoe",
    "email": "user@example.com"
  }
}
```

### Register

```bash
POST /api/auth/local/register
```

**Request Body:**
```json
{
  "username": "johndoe",
  "email": "user@example.com",
  "password": "password123"
}
```

### Get Current User

```bash
GET /api/users/me
Authorization: Bearer <jwt_token>
```

### Forgot Password

```bash
POST /api/auth/forgot-password
```

**Request Body:**
```json
{
  "email": "user@example.com"
}
```

### Reset Password

```bash
POST /api/auth/reset-password
```

**Request Body:**
```json
{
  "code": "reset_code_from_email",
  "password": "newpassword123",
  "passwordConfirmation": "newpassword123"
}
```

## Articles

### List Articles

```bash
GET /api/articles
```

**Query Parameters:**
| Parameter | Example | Description |
|-----------|---------|-------------|
| `populate` | `*` | Include all relations |
| `pagination[page]` | `1` | Page number |
| `pagination[pageSize]` | `10` | Items per page |
| `sort` | `createdAt:desc` | Sort order |
| `filters[featured][$eq]` | `true` | Filter featured articles |
| `filters[category][slug][$eq]` | `tech` | Filter by category slug |
| `filters[author][id][$eq]` | `1` | Filter by author ID |

**Example Request:**
```bash
curl "http://localhost:1337/api/articles?populate=*&pagination[pageSize]=10&sort=createdAt:desc"
```

**Response:**
```json
{
  "data": [
    {
      "id": 1,
      "documentId": "abc123",
      "title": "Getting Started with React",
      "slug": "getting-started-with-react",
      "description": "A beginner's guide to React",
      "content": "<p>Article content...</p>",
      "featured": true,
      "likesCount": 42,
      "commentsCount": 5,
      "bookmarksCount": 12,
      "createdAt": "2024-01-15T10:00:00.000Z",
      "author": { "id": 1, "username": "johndoe" },
      "category": { "id": 1, "name": "Technology", "slug": "tech" },
      "tags": [{ "id": 1, "name": "React", "slug": "react" }]
    }
  ],
  "meta": {
    "pagination": {
      "page": 1,
      "pageSize": 10,
      "pageCount": 5,
      "total": 50
    }
  }
}
```

### Get Single Article

```bash
GET /api/articles/:documentId
```

**Example:**
```bash
curl "http://localhost:1337/api/articles/abc123?populate=*"
```

### Get Article by Slug

```bash
GET /api/articles?filters[slug][$eq]=:slug
```

**Example:**
```bash
curl "http://localhost:1337/api/articles?filters[slug][$eq]=getting-started-with-react&populate=*"
```

## Query Parameters Reference

### Filtering

| Operator | Example | Description |
|----------|---------|-------------|
| `$eq` | `filters[title][$eq]=Hello` | Equal |
| `$ne` | `filters[title][$ne]=Hello` | Not equal |
| `$lt` | `filters[age][$lt]=18` | Less than |
| `$lte` | `filters[age][$lte]=18` | Less than or equal |
| `$gt` | `filters[age][$gt]=18` | Greater than |
| `$gte` | `filters[age][$gte]=18` | Greater than or equal |
| `$in` | `filters[id][$in][0]=1&filters[id][$in][1]=2` | In array |
| `$contains` | `filters[title][$contains]=hello` | Contains (case-sensitive) |
| `$containsi` | `filters[title][$containsi]=hello` | Contains (case-insensitive) |
| `$null` | `filters[image][$null]=true` | Is null |
| `$notNull` | `filters[image][$notNull]=true` | Is not null |

### Sorting

```bash
# Single field
?sort=createdAt:desc

# Multiple fields
?sort[0]=featured:desc&sort[1]=createdAt:desc
```

### Pagination

```bash
# Page-based
?pagination[page]=1&pagination[pageSize]=10

# Offset-based
?pagination[start]=0&pagination[limit]=10
```

### Population (Relations)

```bash
# All relations
?populate=*

# Specific relations
?populate[0]=author&populate[1]=category

# Nested relations
?populate[author][populate]=*
```

### Field Selection

```bash
?fields[0]=title&fields[1]=slug&fields[2]=createdAt
```

## Rate Limiting

The API implements rate limiting to prevent abuse:

- **Public endpoints**: 100 requests per minute
- **Authenticated endpoints**: 200 requests per minute

When rate limited, you'll receive a `429 Too Many Requests` response.
